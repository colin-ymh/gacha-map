# 카테고리 탭 시각 정리

## Request
기존 탐색 동작은 유지하고 앱의 홈과 전체 목록에 어울리도록 카테고리 화면을 정리한다.

## Scope
- 카테고리 탭의 바로가기, 왼쪽 분류, 오른쪽 항목과 제목. `collapsibleShortcuts` 경로 한정.
- Notion 「가챠 카테고리·시리즈 탐색 기획」 §3 확인. 기존 검색창과 분류 → 항목 행, 상품 수, 전체 이동을 유지한다.
- Penpot 서비스 UI의 기존 둘러보기, 홈, 전체 목록 디자인을 기준으로 개선 보드를 만든 뒤 구현한다. 원본 보드 보존.

## Out of Scope
검색 빈 화면, 전체 목록·상세, 데이터·이미지 소스·정렬·API, 신규 글래스 효과와 스크롤 구조.

## Relevant Files
- `apps/mobile/components/organisms/search/GachaBrowseSections.tsx`
- `apps/mobile/components/molecules/BrowseListRow.tsx` (수량 번역과 정보 위계 참조)
- `apps/mobile/constants/colors.ts`, `apps/mobile/messages/*.json` (기존 토큰·문구 사용)

## Plan
1. 바로가기: 기존 크기·피크·라벨 유지, 그라데이션 위 여백 40 → 24로 줄이고 하단 명암은 유지.
2. 분류: 폭 104 유지, 흰 바탕, 좌우 inset 8. 최소 48 높이, radius 12, 14px 라벨(선택 700, 비선택 400). 연회색은 선택에만 적용하고 접근성 선택 상태 표시.
3. 우측: 기존 좌우 20 여백, 제목 15/700·줄높이 22·위 20 아래 12. 전체 12px. 항목 14/600, 그 아래 12px의 현지화 상품 수. 최소 64 높이, 줄 간격 4, 행 구분선 제거, 섹션 말미 12 여백.
4. Sol 구현 후 타입/lint·diff 확인하고 Penpot 개선 보드를 최종 수치에 맞춰 검증한다.

## Verification
변경 전후 모바일 타입 검사·lint, 단일 파일 diff, 번역 키와 색상 토큰 확인. 기기에서 375px 폭 초기 화면, 제목 고정과 마지막 분류, 긴 이름/번역, 밝은 이미지의 이름 대비를 확인할 대상으로 삼는다.

## Risks / Questions
기존 상품 안내지의 복잡함은 남는다. 이번에 소스 변경은 하지 않는다. 선택 메뉴는 긴 번역이나 글꼴 확대에도 최소 높이를 유지하고 줄바꿈을 허용한다. 기기 확인 여부를 별도 보고한다.

## Adversarial Review
Astra 검토: 새 카드/그림자보다 여백과 서체 위계로 가챠 사진에 시선을 남긴다. 공용 기본 모드를 덮어쓰지 않고 조건부 스타일로 한정한다. 섹션 여백을 측정 대상 안에 두고 sticky 인덱스, 이동/선택 좌표, 아래로 당길 때 바운스 방지 및 콜백을 유지한다. Penpot 원본을 덮어쓰지 않는다.

## Final Plan
위 수치의 Penpot 개선 보드를 확인한 뒤 단일 화면 컴포넌트에 적용하고, 검증 결과와 디자인 동기화 상태를 기록한다.

## Implementation and verification
- Astra 검토 → Penpot 개선 보드 작성 및 375×812 PNG 시각 확인 → Sol 구현 → 메인 검사·보드 수치 대조.
- Penpot 서비스 UI의 `화면_둘러보기 탭 - 모바일 (UI 개선)` (302a8f23-f57c-8025-8008-f46f416cebc7)이 현재 시각 기준이다. 기존 보드는 보존했다. Font weight는 기존 Penpot 글꼴과 일치하도록 비선택 400, 항목 이름 600으로 적용했다.
- Notion 기획서 §3-2와 §15-0의 항목 위계·분류 선택·바로가기·고정 스크롤·보드 참조를 최신화했다.
- 모바일 lint 0 errors / 기존 73 warnings, 변경 파일 ESLint 및 `git diff --check` 통과. 타입 검사는 기존 4개 파일 오류와 동일하며 신규 오류는 없음. 설치된 포매터 없음.
- Dev 터널 응답 확인. 실제 아이폰의 글꼴 확대, 긴 번역, 밝은 이미지 가독성 및 터치 스크롤은 미검증. 대표이미지 소스 교체는 별도.
