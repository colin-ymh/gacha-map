### 2. `line` 축에 세 개념이 섞여 있다

| 개념                 | 묻는 것                           | 예                                  |
| -------------------- | --------------------------------- | ----------------------------------- |
| IP·캐릭터·프랜차이즈 | 어떤 콘텐츠·캐릭터인가            | 무민, 후치코, 토미카                |
| 제품 계열·브랜드     | 어떤 이름의 상품군으로 전개되는가 | 푸티또, 1/64PLUS, 포켓토미카        |
| 형태·용도·규격       | 어떻게 만들고 쓰는가              | 컵 가장자리 걸이, 스트랩, 1:64 축척 |

한 상품에 IP와 제품 계열이 **동시에** 붙을 수 있다. `PUTITTO ムーミン`은
IP=무민, 제품계열=푸티또다. 현재 축 정의는 이걸 표현하지 못한다.

## 확정된 정의

codex 검증 결과를 반영한다.

| 축          | 정의                                                                | 담는 것                                                                |
| ----------- | ------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `series`    | **IP·브랜드** — 특정 콘텐츠·캐릭터·프랜차이즈의 정체성              | 무민, 닛코리노, 후치코, **토미카·플라레일·아니아**(제조사 공식 브랜드) |
| `line`      | **제품 계열** — 제조사가 여러 상품을 지속적으로 묶는 상품군 이름    | 푸티또, 1/64PLUS, 캡슐 플라레일, 포켓토미카, 캡슐아니아                |
| (신설 검토) | **형태·용도** — 고유명사를 빼도 구조·재질·부착 방식으로 설명되는 것 | 컵 걸이, 스트랩, 마스코트                                              |

**핵심 변경**: `line`에서 "형태"를 뺀다. `line`은 이제 "제품 계열"만 뜻한다.

형태를 별도 축으로 신설할지는 **미결(Q1)**. 지금 `product_type`(상품 종류) 축이
일부 그 역할을 하고 있어 중복 여부를 봐야 한다.

## 판별 기준 (문자열 비율 대신)

- **IP 판정** — 특정 작품·캐릭터·프랜차이즈의 정체성을 가리키는가
- **제품 계열 판정** — 제조사가 여러 상품을 지속적으로 묶는 상품군 이름인가
- **형태 판정** — 고유명사를 제거해도 구조·재질·부착 방식·기능·규격으로 설명되는가
- **병합 판정** — 동일 대상의 별칭인가. 같은 계열이라는 이유만으로 병합하지 않는다

> ⚠️ **자동 판정은 불가능하다.** 검증된 사전으로 상품→명칭 연결은 자동화되지만,
> 새 명칭의 의미 분류와 부모 관계는 **공식 자료 확인 + 사람 검토**가 필요하다.
> IP 포함률은 분류 규칙에서 빼고 검출 품질 점검용으로만 남긴다.

## Risks / Questions

- **Q1.** 형태 축을 신설할지. 현재 `product_type`(상품 종류, 23개)과 역할이 겹치는지
  먼저 확인해야 한다.
- **Q2.** `line`에 계층(`parent_id`)이 없다. 냥코 상위 계열과 토미카·플라레일 계열을
  표현하려면 `gacha_categories`에 계층을 넣거나, 상위를 series로 올리고 line을
  자식으로 두는 두 방식 중 하나를 골라야 한다.
  현행 `browse_gacha_series`가 루트 목록에서 `parent_id is null`을 요구하므로
  후자를 택하면 노출 규칙도 함께 봐야 한다.
- **Q3.** `series`가 "IP"인지 "IP + 완구 브랜드"인지 정의를 넓힐지. 토미카·플라레일을
  넣으려면 넓혀야 한다. 넓히면 사용자가 "시리즈"라 부르는 직관과 가까워진다.
- **Q4.** 잠정 3건의 공식 자료 확인은 누가 하나. collector 쪽 조사 요청 대상인가.

## Adversarial Review

`20260906` 계획에 대한 codex 검토에서 이미 지적된 것이 이번 문제의 원인이다.

> #7 분류 번복 지표가 분류하려는 속성을 측정하지 않는다. "연결된 활성 IP 수"는
> 수집량·파싱 품질·중복 시리즈·archive 상태·콜라보 빈도에 좌우된다.
> 표본 부족과 자기완결성을 구별하지 못한다.

당시 지표를 "IP 종류 수"에서 "IP 포함률"로 바꿔 대응했다고 판단했으나,
**같은 결함이 남아 있었다.** 두 지표 모두 IP 검출에 의존한다는 점이 동일하다.

교훈 — 지표를 바꿀 때 **전수로 분포를 먼저 보고** 경계가 실재하는지 확인해야 한다.
표본 7개의 공백은 분류 근거가 되지 않는다.
