# 오늘의 가챠 생성 지연과 번역 누락 복구

## Request

운영 점검에서 발견된 오늘의 가챠 생성 시간 초과를 고치고, 번역 준비중 안내 대신 실제 한국어 상품명과 구성품명을 제공한다.

## Scope

- 기존 선정 조건과 응답을 유지하면서 날짜별 첫 생성 비용을 줄인다.
- 활성 상품과 원문이 있는 구성품의 누락 번역을 검토·보충한다.
- 수집기의 재시도 경로를 점검해 과거 누락이 계속 남지 않게 한다.

## Out of Scope

- 홈 레이아웃, 자정 자동 갱신, 원문 삭제, 이미 확정된 한국어명 일괄 재번역.
- 다른 작업의 신고 API 변경.

## Relevant Files

- `supabase/migrations/202611180001_daily_featured_rotation_korean_names.sql`
- `supabase/migrations/202611190001_daily_featured_generation_performance.sql`
- `supabase/tests/daily_featured_rotation_regression.sql`
- Collector 번역 생성·승인 스크립트와 상품 수집 workflow.

## Plan

1. 운영 실행 계획으로 시간 초과 원인을 확인한다.
2. 비용 높은 공백 정규식을 문자열 검사로 바꾸고, 일본어 문자 검사를 C collation으로 실행한다. RPC 인자·선정·권한을 유지한다.
3. 회귀 SQL과 dev의 실제 첫 생성을 검증한 뒤 기존 운영 적용 승인 범위 안에서 prod에 적용한다.
4. 번역 후보를 원문과 비교한다. 의미가 빠진 사전 조합은 그대로 승인하지 않는다. 누락 상품·구성품을 번역하고 조건부 저장한다.
5. 운영 API, 당일 목록 유지, 최근 7일 중복, 실제 번역 잔여량을 확인한다.

## Verification

- 이전 2인자/9인자 함수 환경에서 회귀 SQL 실행.
- 상품명/이미지 null·빈 문자열·제어 공백·일본어 잔존 제외.
- 운영 규모 cold SELECT 실행계획과 dev 첫 생성의 실행 시간 확인. timeout 상향 없이 개선한다.
- 운영 당일 목록 10개와 순서 유지, HTTP 200, 7일 중복 및 번역 잔여량 확인.
- 번역 쓰기는 기존 한국어명을 보존하고 원문 변경에 대한 경합을 검사한다.

## Risks / Questions

- 일부 기존 후보는 상품 설명과 회차를 잃거나 오역되어 자동 승인 부적합하다.
- 원문 이름 자체가 없는 구성품은 추정하지 않는다.
- 앱의 기존 캐시에는 갱신 전 안내가 잠시 남을 수 있다.

## Adversarial Review

- warm 조회만 검증하면 다음 날짜 첫 생성 장애를 놓친다. cold 경로를 별도로 측정한다.
- 단순 미번역 상품 제외는 번역 완료가 아니다. 실제 저장값과 공개 응답으로 확인한다.
- 공백 검사의 변경은 기본 제어 공백 전체를 포함한다. 일본어 문자 범위 검사는 유지한다.
- 번역을 무차별 덮어쓰지 않고 누락만 보충한다. 원문과 현재값이 달라진 경우 쓰기를 건너뛴다.

## Final Plan

2026-11-19 사용자 요청과 기존 운영 반영 승인에 따라 위 순서로 진행한다. 스키마 구조와 공개 계약은 변경하지 않는다. 생성 지연 수정과 번역 데이터 반영 결과를 별도로 검증해 기록한다.
