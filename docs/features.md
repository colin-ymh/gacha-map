# 기능 목록

## 일반 사용자

### 홈 — 지도 뷰 (`/`)
- Supabase에서 `approved` 상태의 샵을 서버에서 fetch
- 네이버 지도에 샵 마커 표시
- 마커 클릭 시 하단 패널(모바일) 또는 사이드바(데스크탑)에 샵 정보 표시

### 검색 (`/search`)
- URL 파라미터 `?q=` 으로 이름/주소 검색 (`ilike`)
- URL 파라미터 `?tag=` 으로 태그 필터
- 결과를 ShopCard 목록으로 표시

### 샵 상세 (`/shop/[id]`)
- 이름, 주소, 설명, 태그, 이미지 갤러리 표시
- `approved` 상태가 아니거나 존재하지 않으면 404

### 찜하기 (`/wishlist`)
- 로그인 필요 (미인증 시 로그인 안내)
- 찜한 샵 목록 표시

### 제보 (`/report`)
- 새 샵 또는 기존 샵 정보 제보 폼
- 제보자 이름/연락처는 선택 항목
- 제출 시 `reports` 테이블에 저장, 성공 메시지 표시

## 관리자 (`/admin/*`)

모든 경로는 인증이 필요합니다. 미인증 시 `/login`으로 리다이렉트.

### 대시보드 (`/admin`)
- 대기 중인 샵 수
- 대기 중인 제보 수
- 승인된 샵 수

### 샵 관리 (`/admin/shops`)
- 상태별 필터 (기본: `pending`)
- 샵 목록 테이블
- 승인 / 거절 버튼 (service role로 RLS 우회)

### 제보 관리 (`/admin/reports`)
- 대기 중인 제보 목록
- 검토 완료 / 해결 완료 상태 변경

### 중복 관리 (`/admin/duplicates`)
- 중복 후보 샵 쌍 목록
- 두 샵 정보를 나란히 비교

### 로그 (`/admin/logs`)
- 미구현 (예정)

## 컴포넌트

### `NaverMap`
- Props: `shops`, `onShopClick`, `center`, `zoom`
- Naver Maps 스크립트 로드 대기 후 지도 초기화
- shops 변경 시 마커 전체 교체

### `ShopCard`
- Props: `shop`
- 이름, 주소, 태그 표시
- 찜하기 버튼 (하트) 포함

### `Header`
- 로고, 검색 / 찜 / 제보 링크
