# collector 인계 — `name_parts.series` 추출 문제 + 제품 계열 3건 분류 조사

작성일: 2026-09-07
대상 리포: `gacha-collector`
관련 계획: `gacha-map/docs/plans/20260907-taxonomy-axis-redefinition.md`
책임 경계: `docs/collector-handoff/20260821-taxonomy-ownership-and-series-refresh.md`

요청 두 건이다. **A는 추출 수정, B는 사실 조사**다.

> **책임 분리** — `20260821` 문서 기준으로 `name_parts` 파싱은 collector, 정규화 RPC와
> 관계 판정은 gacha-map 소유다. 이 문서는 그 경계를 지킨다.
>
> - **gacha-map이 정한다**: 출력 포맷, 축 정의, 관계 의미(`primary`/`collaboration`/`line`)
> - **collector가 한다**: 그 포맷에 맞는 추출, 공식 자료 조사, 근거 제출
> - **근거를 못 찾으면 보류한다.** 추측으로 채우지 말아 달라

## A. `name_parts.series` 에 제품 계열명이 섞여 들어온다

### A-1. 증상

상품명에 `きかんしゃトーマス`(기관차 토마스)가 든 상품 78건의 `name_parts.series.ja` 분포:

| 추출된 series.ja                                                                 | 상품 | 문제                    |
| -------------------------------------------------------------------------------- | ---: | ----------------------- |
| `きかんしゃトーマス`                                                             |   29 | 정상                    |
| `カプセルプラレール きかんしゃトーマス`                                          |   23 | **제품 계열 + IP 결합** |
| `カプセルプラレール`                                                             |   21 | **IP 가 통째로 누락**   |
| `カプセルプラレール きかんしゃトーマス ソドー鉄道の特殊車両編`                   |    1 | 결합 + 부제             |
| `カプセルプラレール きかんしゃトーマス ヒロのふるさと日本のふうけい編`           |    1 | 〃                      |
| `カプセルプラレール きかんしゃトーマス 恐竜パークへようこそ!`                    |    1 | 〃                      |
| `カプセルプラレール きかんしゃトーマスとなかまたち キラキラの鉱山鉄道の仲間たち` |    1 | 〃                      |
| `カプセルプラレール きかんしゃトーマス Go!Go!地球まるごとアドベンチャー編`       |    1 | 〃                      |

**두 종류의 오류가 섞여 있다.**

1. **결합** (23 + 5건) — 제품 계열과 IP가 한 문자열
2. **IP 누락** (21건) — 제품 계열명만 남고 IP가 사라짐

> ⚠️ 2번은 결합을 분리해도 해결되지 않는다. **원본 상품명에서 다시 추출해야 한다.**
> 이 21건이 빠지면 대표 사례의 절반이 미해결로 남는다.

### A-2. 영향 (링크 기준 실측)

`gacha_product_series` 링크를 직접 조회한 결과다. 추출값 분포가 아니라 실제 연결 상태다.

```
きかんしゃトーマス 를 상품명에 포함하는 active 상품:   78건
그중 '토마스와 친구들' series 에 링크된 것:            29건
링크 없음:                                            49건
```

`カプセルプラレール` 로 시작하는 시리즈 엔티티가 **15개** 생겼다 (활성 7 / archived 8).
그중 5개는 상품 0건이며, 같은 일본어 원문의 **한국어 번역만 다른 중복**이다.

```
캡슐 플라레일 토마스
캡슐 플라레일 토마스와 친구들
캡슐 플라레일 토머스와 친구들      ← '토머스'
캡슐플라레일 기관차 토마스          ← 띄어쓰기 다름
캡슐 플레이라일 토마스와 친구들     ← 오타
```

### A-3. 후보 규모 (오류 규모 아님)

아래는 **특정 문자열 조건에 걸린 후보**다. 전부 오류라는 뜻이 아니고, 놓친 것도 있다.

집계 SQL (dev, 2026-09-07):

```sql
with lines as (
  select name_ja from gacha_categories
  where category_type='line' and status='active' and name_ja is not null
),
ext as (
  select p.name_parts->'series'->>'ja' as s, p.id
  from gacha_products p
  where p.status='active' and p.name_parts->'series'->>'ja' is not null
)
select l.name_ja as line_prefix, count(distinct e.s) as compound_names, count(*) as products
from ext e join lines l on e.s like l.name_ja || ' %'
group by l.name_ja order by products desc;
```

| 접두사               | 복합명 |    상품 | 예시                                                 |
| -------------------- | -----: | ------: | ---------------------------------------------------- |
| `PUTITTO`            |     41 |      47 | `PUTITTO ANZEN漫才` · `PUTITTO MUSEUM SERIES`        |
| `おねむたん`         |     20 |      34 | `おねむたん TVアニメ「進撃の巨人」`                  |
| `カプセルプラレール` |      9 |      32 | `カプセルプラレール いっしょにあそぼう！`            |
| `パンダの穴`         |     11 |      17 | `パンダの穴 DELIVERY ZOO` · `パンダの穴 ZOO ZOO ZOO` |
| `ポケットトミカ`     |      3 |       3 | `ポケットトミカ レスキュー!救急消防署編`             |
| `ntc.Puff`           |      2 |       2 | `ntc.Puff ハムスター`                                |
| `ケツ婚指輪`         |      1 |       2 | `ケツ婚指輪 ねこのおケツ`                            |
| `まちぼうけ`         |      1 |       1 | `まちぼうけ スーパー戦隊のおともだち`                |
| `かぷぐるみ`         |      1 |       1 | `かぷぐるみ ふにゅまる！マスコットコレクション`      |
| `1/64PLUS`           |      1 |       1 | `1/64PLUS ダイハツムーヴキャンバス NEWCOLOR`         |
| **합계**             | **90** | **140** |                                                      |

**이 수치의 한계** — 그대로 목표치로 쓰지 말아 달라.

- 반각 공백 하나만 본다. 전각 공백·기호·별칭·중간 삽입은 못 잡는다
- **A-1 의 "IP 누락" 21건은 여기 안 잡힌다** (계열명 단독이라 접두사+공백 패턴에 안 걸림)
- 모집단이 gacha-map 의 `line` 사전(34개)에 종속된다. 사전에 없는 계열은 누락
- 반대로 `PUTITTO MUSEUM SERIES` 같은 **자체 기획명도 포함**되므로 140건 전부가 오류는 아니다

### A-4. 요청 — gacha-map 이 정한 출력 규칙

`name_parts.series` 는 **IP 만** 담는다. 제품 계열은 gacha-map 이 상품명 정규식으로
따로 잡으므로 collector 가 별도 필드로 넘길 필요 없다.

접두사 뒤에 오는 것이 세 종류라 처리가 갈린다.

| 뒤에 오는 것         | 예                                                                                 | `series` 출력값         |
| -------------------- | ---------------------------------------------------------------------------------- | ----------------------- |
| **외부 IP**          | `おねむたん TVアニメ「進撃の巨人」`                                                | `進撃の巨人`            |
| **자체 서브 상품군** | `パンダの穴 ZOO ZOO ZOO`<br>`ポケットトミカ レスキュー!救急消防署編`               | **`null`** — IP 가 없다 |
| **부제·색상·판번호** | `1/64PLUS ダイハツムーヴキャンバス NEWCOLOR`<br>`お風呂で水族館マスコット（再販）` | **`null`** — IP 가 없다 |

> **`null` 을 쓰는 이유** — 이전 초안은 "그대로 두거나 접두사만 유지" 라고 썼는데
> 자기모순이었다. 그대로 두면 복합명 파편이 남고, 접두사만 남기면 제품 계열이
> 다시 series 가 된다. **IP 가 없으면 series 도 없는 게 맞다.**
> 제품 계열 정보는 gacha-map 의 `line` 카테고리가 이미 갖고 있어 잃는 게 없다.

**판정이 애매하면 `null` 로 두고 보류 목록에 남겨 달라.** 잘못 채우는 것보다 낫다.
`PUTITTO`(41개)가 특히 섞여 있다 — `PUTITTO 僕のヒーローアカデミア`(IP)와
`PUTITTO MUSEUM SERIES`(자체 기획)가 공존한다.

### A-5. ⚠️ 한국어 정본이 실제 연결을 결정한다

**일본어만 고치면 해결되지 않는다.**

gacha-map 의 `refresh_gacha_product_series()` 는 엔티티를 `name_ko_norm`(한국어 정규화)
기준으로 식별한다. 일본어 동일성은 보지 않는다.

```
series.ko 가 비어 있으면  → 일본어가 정확해도 링크를 안 만든다
series.ko 가 매번 다르면  → 번역 variant 마다 새 시리즈 엔티티가 생긴다
```

A-2 의 중복 5개(`토마스` / `토머스` / `기관차 토마스` / 오타)가 정확히 이 결과다.

**요청**: 같은 IP 는 항상 같은 `series.ko` 를 쓰도록 **승인된 한·일 정본 쌍**을 유지해 달라.
기존 값도 그 쌍으로 재처리 대상에 포함해 달라.

### A-6. ⚠️ `×` 로 넘기는 방식은 쓸 수 없다

이전 초안이 "복합명에 `×` 를 넣어주면 gacha-map 변경 없이 해결된다"고 썼는데 **틀렸다.**
확인 결과:

- 분해 대상은 `series.ja` 가 아니라 **`series.ko`(한국어)** 다
- 모든 조각이 기존 `gacha_series.name_ko_norm` 과 일치해야 분해가 허용된다.
  하나라도 미등록이면 복합명 엔티티를 그대로 다시 만든다
- 분해에 성공해도 결과가 **전부 `collaboration`** 이 된다. 제품 계열 관계를
  협업으로 오분류한다
- archived 시리즈를 제외하는 조건이 없다

**이 방식은 요청하지 않는다.** A-4 의 규칙대로 IP 만 넣어 달라.

### A-7. 수정 후 gacha-map 이 할 일 (추출 수정만으로 끝나지 않는다)

코드 수정은 **기존 상품 데이터를 바꾸지 않는다.** 아래가 별도로 필요하다.

| 주체      | 작업                                                    |
| --------- | ------------------------------------------------------- |
| collector | 기존 상품 **재추출 후 upsert** (신규 수집분만으론 부족) |
| gacha-map | `refresh_gacha_product_series()` 실행                   |
| gacha-map | `gacha_series_browse` / `gacha_category_browse` MV 갱신 |
| gacha-map | **파편 시리즈 엔티티 정리** — 아래 참조                 |

> ⚠️ RPC 는 `source in ('name_parts','known_product_line_term')` 링크만 지운다.
> `manual` · `collector_llm` · `user_log` 링크는 남는다.
>
> ⚠️ **파편 시리즈 엔티티 자체는 자동으로 사라지지 않는다.** 상품 링크가 0이 되어
> 탐색 목록에서 안 보일 뿐 행은 남는다. 자식 시리즈가 있으면 `rollup_product_count`
> 가 0이 아니라 계속 노출될 수도 있다. gacha-map 이 별도로 archive/병합 판단한다.

재추출 범위에 **A-1 의 "IP 누락" 21건(`series = カプセルプラレール` 만 있는 상품)** 을
반드시 포함해 달라. 결합 분리만으로는 안 고쳐진다.

## B. 제품 계열 3건 — 분류 근거 조사

### 배경

gacha-map 이 축을 재정의했다.

| 축       | 정의                                                                     |
| -------- | ------------------------------------------------------------------------ |
| `series` | IP·브랜드 — 특정 콘텐츠·캐릭터·프랜차이즈의 정체성. **완구 브랜드 포함** |
| `line`   | 제품 계열 — 제조사가 여러 상품을 지속 전개하는 상품군 이름               |

**두 축이 배타적이지 않다.** 완구 브랜드는 브랜드이면서 지속 상품군이기도 하다.
그래서 "자체 캐릭터 세계관이 없으면 `line`" 같은 단순 이분법은 쓸 수 없다.

**collector 는 분류를 확정하지 말고 사실만 제출해 달라. 최종 분류는 gacha-map 이 한다.**

### 제출 형식

각 건에 대해:

| 항목             | 내용                                                    |
| ---------------- | ------------------------------------------------------- |
| 공식 URL         | 제조사 공식 페이지                                      |
| 확인된 사실      | 그 페이지가 이 이름으로 무엇을 묶는다고 설명하는가      |
| 자체 캐릭터 유무 | 고유 캐릭터·세계관이 제시되는가. 이름·설정이 있는가     |
| 외부 IP 사용     | 라이선스 IP 상품이 있는가                               |
| 상위 브랜드      | 더 큰 브랜드의 하위 계열인가 (예: 캡슐 아니아 → 아니아) |
| 미확인 사항      | 자료로 확인 못 한 것                                    |

> 공식 사이트에 "시리즈" / "브랜드" 라고 쓰여 있다는 것만으로 확정하지 말아 달라.
> 그 명칭이 실제로 무엇을 묶는지가 기준이다. 저작권 표기도 참고 자료일 뿐이다.
>
> **근거를 못 찾으면 "미확인" 으로 제출해 달라.** 추정으로 채우지 말 것.

### B-4. 조사 대상 4건 추가 (2026-09-08)

브랜드 11건을 `line` → `series` 로 옮긴 뒤 남은 25건을 다시 훑었더니, 아래 4건도
같은 성격으로 보인다. **B-1~B-3 과 같은 형식으로 함께 조사해 달라.**

#### `네코의 펜꽂이` / `ネコのペンおき` (상품 9건)

```
ネコのペンおき®６                      ← ® 등록상표 표기
垂れ耳・長毛ver.ネコのペンおき5
ぺんてるのネコのペンおき                ← 펜텔 콜라보로 보임
ネコのペンおき
```

**`®` 표기가 있다.** 등록상표라면 제조사가 브랜드로 관리한다는 뜻이다.
`ぺんてる`(펜텔) 콜라보판도 있어 외부 협업이 성립하는 이름이다.

#### `생물대도감` / `いきもの大図鑑` (상품 8건)

```
いきもの大図鑑 くわがた12               ← 사슴벌레 12탄
いきもの大図鑑 かぶとむし10             ← 장수풍뎅이 10탄
いきもの大図鑑レプティクス 恐竜         ← '레프틱스' 서브라인
いきもの大図鑑アドバンス SELECTED EDITION 02   ← '어드밴스' 서브라인
```

**서브라인(`レプティクス` · `アドバンス`)이 존재한다.** 하위 계열을 갖는 건
단일 상품군이 아니라 브랜드의 특징이다.

#### `워터돔팩토리` / `WaterDomeFactory` (상품 7건)

```
WaterDomeFactory キノコ編
WaterDomeFactory 海洋生物編
WaterDomeFactory 猫砂スノードーム２
WaterDomeFactory フラッペ
```

`〜編` 테마 전개. 외부 IP 없이 자체 소재로 회차를 잇는다.

#### `치루코토` / `ちるこっと` (상품 5건)

```
ちるこっと ラバーキーチェーン
ちるこっと アクリルスタンド
```

**다른 셋과 성격이 다를 수 있다.** 뒤에 붙는 게 소재·테마가 아니라
**상품 형태**(러버 키체인 · 아크릴 스탠드)다. `ちるこっと` 가 캐릭터인지,
아니면 IP 에 씌우는 형태 이름인지 확인 필요하다.

### 참고 — IP 포함률은 판단 근거가 아니다

위 7건(B-1~B-4)은 상품명에 외부 IP 가 포함되는 비율이 **전부 0%** 다.
그러나 **이 지표는 폐기했다.** `line` 34건 전수로 재보니 100 에서 0 까지 연속
분포라 경계가 없고, 지표가 재는 것은 형태가 아니라 "현재 IP 사전과 문자열 규칙으로
검출되는 비율"이다.

푸티또(34.2%)가 반례다 — 제조사가 스스로 "피규어 브랜드"라 부르면서 컵 가장자리에
거는 형식을 공유한다. **브랜드와 형태는 반대 개념이 아니다.**

수치는 참고만 하고, 공식 자료에서 확인한 사실로 판단해 달라.
