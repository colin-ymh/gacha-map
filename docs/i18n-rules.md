# i18n Rules

## General
- Use i18n for user-facing text whenever possible.
- Avoid hardcoding strings directly inside components.

## Languages
- Supported languages:
    - Korean
    - English
    - Japanese
    - Chinese
- Default language: Korean.

## Scope
- Move buttons, labels, helper text, error messages, and shared UI text into i18n resources.
- Temporary hardcoded text is allowed only for short-lived prototyping, and should be replaced before completion.

## Layout Considerations
- Consider text expansion in non-Korean languages.
- Avoid layouts that depend too heavily on fixed-width text.
